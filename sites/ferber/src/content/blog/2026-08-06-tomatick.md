# Tomatick: A Menu Bar Timer That Stays on the Mac

I did not want another Electron pomodoro. I did not want a website with a login. I wanted a stopwatch in the menu bar that I wrote, that I can read, and that does not phone home.

[Tomatick](https://tomatick.us) is that app. Timer, stopwatch, alarm, pomodoro. One icon. MIT. Source on [GitHub](https://github.com/MichalAFerber/tomatick).

## What it does

- **Timer** — `25m`, `1h30m`, `90s`, `2:30`. Live `M:SS` in the menu bar. It keeps ringing until you dismiss it.
- **Stopwatch** — counts up, laps, pause/resume/reset from the menu.
- **Pomodoro** — 25 / 5 / 15 by default, auto-advance, long break every fourth cycle. Optional Focus/DND during work.
- **Alarms** — one-shot (date + time) or recurring (a time on chosen weekdays). Looping sound, notification, snooze.
- **Several at once** — pin one to the menu bar; the rest stay listed with their own counts.
- **History** — every start/pause/complete/phase/alarm is a SQLite row. Export CSV or JSON.

No Dock icon. No window you have to find. Settings, presets, and alarms live in `~/Library/Application Support/Tomatick/`. Launch at login is a per-user LaunchAgent, not a notarized helper that needs Apple's blessing.

## Why this stack

[rumps](https://github.com/jaredks/rumps) wraps `NSStatusItem` / `NSMenu`. PyObjC for the native bits. Python 3.11 or 3.12 (rumps is not on 3.13 yet). The timing, alarms, and history have **no macOS imports**, so pytest runs on Linux in CI. The Mac job is an import smoke plus the same suite.

I can build a `.app` with py2app. I cannot, and will not, pay the Apple Developer Program ninety-nine dollars a year so a kitchen timer can be signed. The dmg is unsigned. First launch: right-click → Open. If Gatekeeper still sulks:

```bash
xattr -dr com.apple.quarantine /Applications/Tomatick.app
```

Apple Silicon only. The bundle is an arm64 Python. Intel Macs are not a target. I will not ship a universal binary I cannot test.

Notifications are reliable from the packaged app (they want a bundle id). From `python -m tomatick` you still get sounds and menu updates. That is an honest limitation, not a bug I will "fix" by wrapping it in Electron so the notification center is happier.

## What I refused

Clock.app can time a boiled egg. A website pomodoro can guilt you in a tab. Neither keeps a timestamped history of *what I actually ran*, exports it, or runs four sessions without becoming a project-management suite.

Nothing leaves the Mac. There is no account. The site at tomatick.us is Astro on Cloudflare Pages so the dmg has somewhere honest to point — cookieless analytics, self-hosted font, a CSP the Playwright harness actually exercises. The app does not talk to the site.

## How to get it

Latest `.dmg` on the [Releases](https://github.com/MichalAFerber/tomatick/releases) page. Drag to Applications. Look at the right side of the menu bar.

If you want to run it from source:

```bash
python3.12 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python -m tomatick
```

I use this every day. That is the review. If you need a signed, notarized, Intel-and-ARM, iCloud-synced timer, you already know the names in the App Store. This one is the other kind.
