# My 3-2-1 Backup Strategy in Practice

Three copies. Two media. One off-site. Everyone can recite it. The [Wasabi post](/2026-03-23-wasabi-s3-storage/) is the off-site *leg*. This is the whole sentence.

## The three copies

1. **Source** — the live disk. Mac Mini, a Proxmox VM, a droplet's `/opt`, the phone's `/DCIM` until Immich has it.
2. **On-site second medium** — Proxmox Backup Server (PBS) on the LAN, plus NAS where it still earns a slot. Different disk, different box, same building.
3. **Off-site** — Wasabi via rclone. Cheap, S3-compatible, no egress games that matter at my scale. [Cryptomator](/2026-04-07-cheap-private-cloud-backup-cryptomator/) when the provider should see ciphertext only.

If a copy is "the Time Machine volume on the same desk as the Mac," that is not two media. That is a second folder.

## How it actually flows

Most Linux boxes in the lab have a small, boring job: tarball or rclone the bits that matter to **PBS** on a timer (`rclone-to-pbs.timer`, or a host script at 03:something). PBS is the on-site vault. Retention is a script, not a feeling — keep N days, keep a minimum count, alert if the newest backup is older than three days.

PBS then mirrors to **Wasabi** (`ferber-pbs` and friends). Off-site is not a second cron on every VM talking to the internet. Off-site is one well-watched pipe from the backup server.

Macs: local snapshot discipline plus the encrypted cloud vault. Photos: Immich is the live library; Wasabi sits under it on `kkweb-002` via s3fs. That is still 3-2-1 if the live disk, the object bucket, and a PBS-side copy disagree about fate.

## What I refuse to call a backup

- RAID. That's availability.
- A Git repo. That's history for text I already intended to publish.
- "It's in Google Photos." That's a vendor with a ToS.

A backup is a copy you have **restored**. I test restores. Not every week. Often enough that a restore is a procedure, not a prayer.

## The 3-2-1 I tell people to start with

1. External disk you unplug (copy 2, media 2).
2. Wasabi or Backblaze B2 with rclone (copy 3, off-site).
3. A calendar reminder that says "restore one file."

PBS and Proxmox come later. The shape is the same at every scale. I just happen to have a homelab that made the middle box a backup server instead of a USB drive in a drawer — and I still keep the drawer version for the things that are only on a Mac.
