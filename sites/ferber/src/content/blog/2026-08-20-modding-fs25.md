# Michal's InGame Mods for FS25

I did not want a folder of per-vehicle XML edits. I wanted one zip that tells Farming Simulator 25: work at whatever speed I am going, fill the trailer like a silo, and put real horsepower in the big iron.

That zip is [Michal's InGame Mods](https://michalaferber.github.io/Modding-in-FS25/). MIT. One Lua file holds the config. ~50 KB. Base game and mod vehicles. Singleplayer.

## What it actually does

**No speed limit.** Every working-speed clamp funnels through `Vehicle.getSpeedLimit`. The mod returns "no limit." Cultivators, seeders, sprayers, balers, cutters — they work at the speed you are doing. Damage-based slowdown dies with it. Factory top speed gets a 2× multiplier. Cruise will not recap you until 200 km/h.

**Max capacity.** A pattern table matches vehicles by config-path substring and rewrites fill-unit capacity on load. Grain trailers and loading wagons go to 940,000 liters. Fill mass is ignored by default, because 940,000 liters of wheat is about 730 tons and the physics engine has opinions.

**Max horsepower.** Torque is scaled at the source — `VehicleMotor.getTorqueCurveValue` — so it does not care how GIANTS stored the curve. Explicit overrides for John Deere 9R/9RX, Case IH Steiger, CLAAS XERION 12, Volvo VNX 300, Mack Anthem: 1,156 hp. Adding another brand is one line in a table.

The shop page still shows factory numbers. It reads cached store data. The tractor pulls 1,156. The brochure lies.

## Proof, not promises

The mod logs everything it touches. Prefix `MIGM:` in `log.txt`. Before and after, per vehicle, every load:

```
MIGM: volvo/vnx300.xml -> 1156 hp (368 kW -> 850 kW, scale 2.31)
MIGM: krampe/sks30_150.xml -> 940000 l (was 59400 l)
MIGM: johnDeere/series9RX830.xml -> 1156 hp (672 kW -> 850 kW, scale 1.27)
```

If a vehicle got patched, there is a line. If there is no line, it did not. Grep and know.

## Install

Drop `FS25_MichalsInGameMods.zip` into `Documents\My Games\FarmingSimulator2025\mods\`. Do not extract it. Do not rename it — the filename *is* the mod name, and GIANTS rejects dots and version suffixes. Enable it on the save. Optional: grep the log.

Latest zip is always the GitHub Release asset. Tag matches `modDesc.xml`. CI zips `mod/` with `modDesc.xml` at the root.

## Make it yours

Everything lives at the top of `scripts/MichalsInGameMods.lua` inside the zip. Change values, re-zip, done.

```lua
MIGM.TOP_SPEED_MULTIPLIER = 2.0   -- physics gets comedic above ~3.0
MIGM.CRUISE_MAX_KMH       = 200

MIGM.CAPACITY = {
    ["pacesetter"] = 940000,
    ["tdk301"]     = 60000,    -- add your own trailers here
}
MIGM.IGNORE_FILL_MASS = true

MIGM.BIG_TRACTOR_HP = 1156
```

Not sure of a config path? Set `MIGM.DEBUG = true`, load in, copy the distinctive substring into the table. That is the whole workflow.

## Known quirks

Singleplayer only. The motor changes will not sync cleanly across clients, and the mod says so in `modDesc.xml`.

Unload speed is unchanged. Tipping 940k liters at a sell point still takes a while. That is discharge rate, not capacity.

Game patches can rename hooks. The log will tell you exactly where. That is on purpose.

The landing page is a self-contained HTML file, same instinct as the rest of the small tools. The mod never phones home. If you want a different number than 1,156, the Lua is right there.
